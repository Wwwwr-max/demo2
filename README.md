# demo2：命名实体识别（NER）任务

本项目使用本地 `bert-base-chinese` 和 `chinese-bert-wwm` 预训练模型，在 MSRA 和微博两个中文命名实体识别数据集上训练与测试。模型对输入句子中的每个字符进行分类，完成地点、机构、人物等实体的识别。

## 框架组成

```text
demo2
├── demo2_config.json       # 参数配置
├── config.py               # 读取 demo2_config.json
├── dataset.py              # 数据读取、Dataset、标签处理和 tokenizer
├── model_m.py              # 模型
├── train.py                # 训练入口
├── test.py                 # 测试入口
├── requirements.txt        # 第三方依赖
├── data/
│   ├── MSRA/               # MSRA 训练、验证、测试数据
│   └── weibo/              # 微博训练、验证、测试数据
├── pretrain/
│   ├── bert-base-chinese/  # bert-base-chinese 本地预训练模型
│   └── chinese-bert-wwm/   # chinese-bert-wwm 本地预训练模型
├── saved_models/           # 四组实验的验证集最优权重
├── log/                    # TensorBoard 日志
└── picture/                # 训练结果截图
└── configs/                # 模型保存参数
```

## 各模块说明

- `demo2_config.json`
  保存 MSRA、微博数据路径，`max_length`、`batch_size`、学习率、epoch 数、早停轮数，以及两个本地预训练模型路径。

- `config.py`
  读取 `demo2_config.json`。

- `dataset.py`
  `read_data()` 按空行切分句子，每行读取一个字符及其 BIO 标签。
  `Mydata` 把字符串标签转换成类别编号。
  `make_collate_fn(tokenizer, max_length)` 对一个 batch 的字符序列进行截断、填充，并生成对应的标签；非有效位置的标签使用 `-100` 忽略。

- `model_m.py`
  `Mymodel` 加载bert骨干加个linear

- `train.py`
  以此训练数据集和模型的不同组合，根据验证集的f1准确率来保存模型，同时设置早停机制

- `test.py`
  分别加载四组实验的验证集最优权重，在 MSRA 和微博测试集上计算准确率和prf

## 数据格式

每行保存一个字符和对应的实体标签，空行表示一句结束：

```text
北 B-LOC
京 I-LOC
是 O
中 B-ORG
国 I-ORG
的 O
首 O
都 O

我 O
在 O
上 B-LOC
海 I-LOC
```

字段含义：

- `O`：不属于实体
- `B-*`：实体开始位置
- `I-*`：实体内部位置

数据规模：

| 数据集 | 训练集 | 验证集 | 测试集 | 标签类别 |
| --- | ---: | ---: | ---: | ---: |
| MSRA | 5000 句 | 1000 句 | 1000 句 | 7 |
| Weibo | 1350 句 | 269 句 | 270 句 | 17 |

MSRA 包含 `LOC`、`ORG`、`PER` 三类实体；微博包含 `GPE`、`LOC`、`ORG`、`PER`，并区分 `.NAM` 与 `.NOM`。

## 模型与训练配置

- 预训练模型：`./pretrain/bert-base-chinese`、`./pretrain/chinese-bert-wwm`
- 最大长度：`max_length=512`
- Dropout：`0.1`
- 优化器：AdamW
- 学习率：`1e-5`
- 批大小：`12`
- 最大训练轮数：`12`
- 早停轮数：`patience=3`
- 损失函数：CrossEntropyLoss

查看 TensorBoard 曲线：

```bash
tensorboard --logdir=./log
```

每个实验的日志单独存放：

```text
log/MSRA_bert-base
log/MSRA_bert-wwm
log/weibo_bert-base
log/weibo_bert-wwm
```
